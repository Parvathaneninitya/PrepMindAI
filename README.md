## 📌 Project Overview
**PrepMind AI** simulates an end-to-end technical recruitment workflow. The platform combines modern product landing page design principles with interactive mock interview capabilities, including browser-native speech recognition, dynamic technical evaluations, an integrated code sandbox, and an instant assessment scorecard.

---

## ✨ Key Features

- **Modern SaaS Landing Page Structure:**
  - High-conversion Hero section with interactive CTA buttons.
  - 3-tier pricing matrix with custom plan triggers and modal routing.
  - Multi-stage feature breakdown explaining the evaluation pipeline.
  - Mobile-responsive layout optimized across all viewport sizes.

- **Interactive AI Mock Interview Engine:**
  - **Stage 1 (HR & Introduction):** Candidate profile and background check.
  - **Stage 2 (Core CS Concepts):** Technical Q&A across OOPs, memory management, and multithreading.
  - **Stage 3 (Code Sandbox):** In-browser code editor for algorithmic challenges.
  - **Stage 4 (System Design):** Scalability and architecture-focused problem solving.

- **Audio & Evaluation Capabilities:**
  - **Web Speech API Integration:** Real-time speech-to-text voice input and voice synthesis output.
  - **Smart Evaluation Algorithm:** Keyword extraction, input depth analysis, and immediate feedback logic.
  - **Final Performance Scorecard:** Dynamic scoring metrics (0–100), detailed per-stage breakdown, and hiring recommendations.
